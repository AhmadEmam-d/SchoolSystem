Good question! Here's the best workflow for updating your hosted project:
Every time you make changes:

Make your code changes in Visual Studio
Rebuild the backend:

bash
cd "C:\Users\fagr\source\repos\SchoolSystem\SchoolSystem.Api"
dotnet publish -c Release -r win-x86 --self-contained true -o "C:\Users\fagr\Desktop\publish_selfcontained"

Update appsettings.json in publish_selfcontained with correct connection string
Delete appsettings.Development.json from folder
Zip contents:

powershell
Compress-Archive -Path "C:\Users\fagr\Desktop\publish_selfcontained\*" -DestinationPath "C:\Users\fagr\Desktop\app_new.zip" -Force

Go to MonsterASP → wwwroot → Clean
Upload app_new.zip → Unzip
Restart AppPool

For frontend changes:

Make React changes
npm run build
Drag new dist folder to Netlify → it auto-deploys
